## 5. ENG1과 맞춘 것 (master를 합친 뒤)
- 병사: 붙잡기와 병사 체력 깎기는 ENG1의 en2Block에 맡겼다(u.block = 붙잡는 수). 내 쪽은 싸움, 쓰러짐, 재배치만 한다. 체력을 이중으로 깎지 않는다. 병사의 방어(sArmor)는 en2Block이 모르므로 유효 체력(sHp / (1 - sArmor))으로 녹였다. en2Block이 없는 빌드에서는 예전 내 붙잡기 코드가 돈다.
- 공포: e.fearF만 주고 감속은 ENG1이 한다(이중 감속 없음). 장승의 숨은 적 드러내기도 ENG1의 조명 규칙(en2Lights)이 맡는다.
- 상성 표시: mech, ghost, yokai, spirit을 인정(변신한 적은 e.F). leap 적은 병사를 넘는다.
- 탑 멈춤은 내가 걸지 않는다(en2StunTower는 ENG1). 거북선, 화룡선(tough)은 멈춤이 절반 시간에 풀린다.
- 신의 방패함, 이지스는 적 탄(kind ebomb, eshell)을 사거리 안에서 떨어뜨린다(g.proj에서 빼고 blast flak).

## 6. 탑 설계 요약
- 대공포(hit a): 팔랑크스 = 초연사, 작은 적 배수, 6단계 사거리 안 하늘 적 상시 감속 / 고사포 = 큰 폭발과 감속, 6단계 4갈래 추가 폭발과 갑옷 깎기
- 유도탄: 장거리 요격탄 = 사거리 8.5까지, 우두머리 배수, 6단계 체력 15% 아래 처형 / 다탄두 = 3~6표적, 땅과 바다도, 6단계 기절
- 기관포(hit ga, 갑옷에 약함): 철갑 = 갑옷 무시와 쌓이는 깎기, 6단계 10발마다 고폭탄 / 쌍열 벌컨 = 쏠수록 2~3배 빨라짐, 6단계 화상과 두 번째 표적
- 저격: 대물 = 우두머리와 갑옷 배수, 기절, 6단계 우두머리 최대 체력 3% 덤 / 관측조 = 표식 20~40%, 6단계 전장 어디든과 표식 번짐
- 로켓(hit gs): 집속 = 8~14발과 자탄, 6단계 기절 / 소이 = 불 장판, 6단계 넓고 오래
- 레이저: 표적이 바뀌어도 세기 유지 / 프리즘 = 2~5갈래 / 집속 = 일직선 관통, 6단계 화면 끝까지
- 테슬라: 폭풍 코일 = 6~12연쇄, 6단계 5번째마다 범위 전체 / EMP = 범위 전체, 기계 2~2.5배와 긴 기절, 보호막 깸, 6단계 봉인
- 비행장: 전투기 1~4대 / 폭격 = 폭탄, 6단계 3발씩과 불 / 요격 = 하늘 먼저, 공대공 미사일, 6단계 전장 어디든
- 전함(물): 바다 1.6배 / 순양함 = 대공 미사일(hit gas), 6단계 적 탄 요격 / 드레드노트 = 2~4문 일제 사격, 6단계 기절과 밀어내기
- 거북선(물): 양현 포 + 용머리 화염, 튼튼 / 화룡 = 화염, 6단계 하늘도 태우고 불 장판 / 판옥 = 포 4~7문, 주변 수상 탑 피해 +15~30%
- 신기전(hit ga): 대신기전 = 큰 로켓과 불똥 / 백발 = 12~26발, 6단계 4번째마다 두 배
- 장승(조명): 공포 20~50%, 기운 피해 / 천하대장군 = 주기 기절 파동, 6단계 봉인과 요괴 밀어내기 / 지하여장군 = 받는 피해 +20~40%, 6단계 체력 10% 아래 처형
- 병영(hit g): 병사 3명 / 방패대 = 2~3명씩 막음, 6단계 3초 복귀와 가시 / 화랑 = 빠른 칼과 치명타, 6단계 4명과 주변 베기
- 서낭당: 봉인 2~7초, 귀신과 요괴 1.6~2.2배 / 봉인 부적 = 보호막과 가속 벗김, 2~3장, 6단계 8초마다 봉인진 / 벽력 = 범위 벼락과 기절, 6단계 4번째마다 큰 벼락
- 기존 10종 6단계: 5단계의 1.7~2배. 특수 효과는 3절 표와 data.js
- 합체 8종: 1단계로 시작, 재료가 6단계면 한 개마다 +1단계, 강화 1000 / 1500. 자리는 fuseTowers의 첫 인자(수상 합체는 물 쪽 재료 칸). 들인 금화, 처치, 피해 합산
- 관리자 탑: 값 0, g.admin일 때만. 천벌포(전장 어디든 고정 피해), 수호룡(유닛)

## 8. 봇과 sim
- 봇: 편성(g.towersOk)만 씀. 길 표본을 영역별로 세고, 다가올 적의 영역 비율과 지금 그 영역을 막는 화력을 비교해 모자란 영역의 탑을 먼저 짓는다. 바다 적이 오는데 수상 탑이 없으면 3배 가중. 갈래는 적 구성으로 고름. 합체 상대 옆자리를 좋아하고 조건이 되면 바로 합체. makeBot(g, { noFuse: 1 })로 합체 끔.

## 10. 남은 문제와 합칠 때 볼 것
- 수치는 허수아비 기준 1차 조정이다. 실제 판에서의 균형(특히 다탄두 미사일, 폭격 편대, 화룡선의 범위 화력)은 밸런스 갈래가 sim으로 다시 볼 것.
- 판 설계 갈래의 판이 아직 없어 봇 완주는 시험 판 5개 기준이다.
- 화면 갈래가 할 일: gacha.js가 TW_RARITY를 읽게, 전투 쟁반이 t.hit(갈래별 영역)을 보이게, 합체 단추(fuseOptions, fuseTowers), 관리자 탑은 opts.admin일 때만 목록에.
- 그리기 갈래(REN1)가 아직 안 합쳐져 새 탄과 유닛은 빛나는 점으로 보인다. 위 4절 표가 계약이다.
- 사거리 30인 탑(천리 표적수, 에이스 편대, 뇌신탑, 천벌포)은 사거리 원이 화면보다 크다. 화면에서는 "전장 전체"로 표시하는 편이 낫다.
- gachaflow.py는 확률 항목 하나가 실패한다: TOWER_ORDER가 24종이 되면서 gacha.js가 새 14종을 임시로 희귀 등급에 넣어 탑마다 확률이 옛 기대값(일반 15, 희귀 7.5, 전설 5)과 달라졌다. 화면 갈래가 소환 풀을 TW_RARITY로 바꾸고 기대값을 고치면 된다(gacha.js는 건드리지 않았다). metaflow, fitcheck는 돌리지 않았다.
- 한글 문구를 더했으니 빌드 전에 `python3 tools/font_subset.py src node_modules out/font.css`.
