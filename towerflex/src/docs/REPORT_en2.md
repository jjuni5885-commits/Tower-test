# EN2 보고: 2장 '저주받은 밤' 적 그림 (2026-11-12)

## 바꾼 파일
- 새 파일: `src/art_enemy_ch2.js` (적 16종 + vampbat, 최상위 이름은 모두 e2 / E2 로 시작)
- 시험 도구: `tools/en2_hook.py`(out/index.html 사본에 시험 고리 __EF, __SP, __EI 를 끼움, src 는 안 건드림), `tools/en2_board.py`(그림판), `tools/en2_battle.py`(전투 캡처), `tools/en2_hash.py`(기존 적 픽셀 해시), `tools/en2_perf.py`(성능)
- `src/art_enemy.js` 는 한 줄도 고치지 않음. 남의 파일에 넣은 고리 없음.
- 하나 보탠 자료: `ENEMIES.vampbat` 이 없을 때만 최소 자료(size 0.6, fly, form: 1, ch 없음)를 넣음. enemyFrames 가 ENEMIES[k] 를 읽기 때문. ENG1 이 따로 넣으면 그쪽이 쓰임.

## 그림 방식
- 기존 방식 그대로: 세 번 그리기(크기 재기, 외곽선, 색칠), `EN_DRAW[k] = { n, top, f(x, H, p) }`, enemyFrames 결과 구조, 흰 스티커 테두리, 맞을 때 흰 실루엣과 > < 눈, 오른쪽이 진행 방향, 기준점 발밑.
- 다른 점: 2.5~3등신, 남보라 먹색 외곽선(e2Ink), 오른쪽 아래 그늘 띠와 왼쪽 위 달빛 테두리광(e2F, 한 번만 잘라 두 띠를 칠함), 빛나는 눈(e2Eye). 좌표는 H 배수, y 는 위가 +.
- 덩치: 1장 찹쌀떡과 전투 크기에서 무게가 맞도록 가는 적은 1.04~1.3배 키워 그림(파일 끝 K 표). 기준점과 외곽선 굵기는 그대로.
- 대표색 표 `E2_TINT` (처치 연출, 도감 바탕용으로 내어 둠).

## 합칠 때 알아 둘 것 (REN2, ENG1)
- scarab 은 `EN_DRAW.scarab.top = 1`. 지금 render.js 는 top 을 spider, arachne 키로만 판정하므로 `EN_DRAW[e.k].top` 으로 바꿔야 진행 방향으로 돈다(가운데 규칙은 거미와 같음).
- 변신 모습은 `enemyFrames('vampbat', S)`. e.form 을 그림 키로 쓰면 된다.
- pumpking, count 는 n = 6 (폭이 넓어 성능 때문). 장면 번호는 fr.n 으로 나눌 것(기존 코드와 같음).
- 떠다니는 적(phantom, count, reaper)과 수레(coffin)는 거리 기준 장면이어도 어색하지 않게 그렸음. 시간 기준으로 돌리면 더 자연스럽다.
- 상태별 그림(늑대인간 폭주, 원혼 흐려짐)은 따로 없음. 투명도와 색 입힘으로 처리할 것.

## 남은 문제
- 36px 칸에서는 얼굴 세부(꿰맨 자국, 단추 눈)가 뭉개져 실루엣과 대표색으로만 구별된다. 정면 날개인 bats, vampbat, gargoyle 은 색으로 구별.
- 좀비와 미라는 무섭다기보다 아직 익살스러운 편.
- 흰 스티커 테두리와 > < 눈은 기존 방식 그대로라 공포 분위기와 조금 어긋난다(같은 게임으로 보이게 유지).
- 달빛 테두리광은 작은 조각에서는 성능 때문에 생략.
- 전투 확인은 옛 8x14 판과 1장 지형 위에서만 했다. 2장 지형(어두운 묘지) 위에서는 다시 볼 것.
- 호박 대왕과 백작은 3.5~4칸 폭이라 좁은 길에서 옆 탑을 가린다.
