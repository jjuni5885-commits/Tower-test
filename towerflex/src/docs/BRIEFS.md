## STGA 1장, 2장 판 설계 / STGB 3장, 4장 판 설계 (각 시간 예산 100분)
소유: STGA는 src/stages_ch1.js, stages_ch2.js / STGB는 stages_ch3.js, stages_ch4.js. data.js의 CHAPTERS 중 자기 챕터 줄, STORY와 SPEAKERS는 자기 판 파일 안에서 추가(STORY['c1s01'] = ... 식). tools/sg*.js
1. 챕터마다 12판(SPEC 4절 스키마). 사용자 요구: "각단계는 너무 똑같이 하지말고 그것도 테마를 가지고 해서 한판한판 도전", "끝판이 너무 짧아", "하루만에 깰수 있는 게임은 곤란해", "바다도 좀 나오고", "비행기도 나오고 로케트도 나오고". 판마다 길 모양(길 1~3개, 갈림길, 엇갈림, 나선, 고리, 성문이 가운데인 판 등), 지형 테마, 도전 규칙, 적 구성이 달라 매 판이 다른 문제가 되게. 같은 챕터 안에서 같은 규칙은 두 번까지. 10 x 17 격자를 넓게 쓰고, 건설 가능한 칸이 길 주변에 충분하되 명당이 한정되게.
2. 보스는 4, 8, 12판(3장은 10판에 항공모함 추가). 웨이브 수는 16~30(뒤로 갈수록 김). 새 적은 한 판에 하나씩 소개(intro). 적 키는 SPEC 5절.
3. 균열 판: 다른 세계의 적이 균열로 새어 들어오는 판을 넣어 초반부터 바다와 하늘을 보여 줄 것. 1장 6판은 바다 균열(물 넓은 판, 3장의 고속정과 드론이 섞임, 수상 탑이 필요), 1장 10판은 하늘 균열(항로, 전투기와 순항 미사일과 헬기), 2장 6판은 바다 균열(4장의 수적선과 물귀신), 2장 10판은 공습 균열(폭격기와 전투기). 3장과 4장은 자기 적으로 바다 판 3개 이상, 항로 판 3개 이상(3장), 4장 12판 이무기는 바다에서 시작해 용이 되어 항로로.
4. need(그 판에 꼭 필요한 탑)와 reward: need에 든 탑은 시작 탑(archer, catapult, flak)이거나 그 앞 판들의 확정 보상(reward.tower)으로 반드시 받게. 확정 보상 권장 순서: 1장에서 frost, ballista, gatling, warship(5판, 바다 균열 직전), barracks, sam(9판, 하늘 균열 직전), 2장에서 arcane, bell, jangseung, shrine, tesla, 3장에서 sniper, rocket, airbase, laser, cannon, 4장에서 singijeon, turtle, flame, alchemy, mint. 나머지 판은 소환권 2~3장이나 보석.
5. 이야기: 판마다 2~4줄 작전 브리핑(기존 인물 볼튼 대장, 리아, 토르크, 미르, 카엘의 말투를 살리고 챕터마다 그 세계의 안내자 한 명 추가), 챕터 시작과 끝 대사(STORY['c1in'], ['c1end']). 어린이도 하니 순하게, 유머 조금. 판 이름, 지역 이름, desc, ruleName, ruleDesc.
6. 수치(gold, hpMul, bud)는 뒤로 갈수록 오르게 초안만(최종은 밸런스 갈래). CHAPTERS의 open.stars(앞 챕터 별 26 안팎), gate({5: 8, 9: 18} 안팎).
7. 검증: node tools/checkmaps.js 전 판 통과(길, 뱃길, 항로), 판마다 봇으로 한 번씩 돌려 오류 0(tools/sim.js), 판 미리보기 그림판(48판을 작은 지도로 나란히, tools/sgsheet.py)을 캡처해 Read로 직접 보고 길 모양이 겹치는 판은 다시 짜기. 지형 테마 그림이 아직 없으면 기존 테마로 대신 그려 확인.

## UIA 전투 밖 화면 (시간 예산 120분)
소유: src/chapters.js, src/loadout.js, src/ui_art2.js, src/style_ch.css, ui.js의 타이틀, 지도, 판 창, 도감, 설정 부분, ui_art.js, meta.js, gacha.js, template.html, tools/uia*.py
1. 새 상표와 타이틀: '철옹성' 큰 로고와 부제 '차원전쟁', 네 세계의 균열이 성 뒤로 열린 서사적인 타이틀 그림(ui_art2.js). 사용자가 "초등학생용 같다"고 했으니 타이틀과 공통 화면은 귀염 파스텔보다 한 단계 성숙하고 임팩트 있게(굵은 로고, 깊은 색, 빛). 1장 화면은 귀염 유지.
2. 흐름: 타이틀 → 챕터 고르기(카드 4장: 분위기 그림, 진행 별, 잠금 조건) → 챕터 지도(판 12 노드 + 보너스 3 노드, 챕터마다 지도 그림과 색이 다름: 1장 파스텔, 2장 어두운 보라와 주황, 3장 강철 남색과 호박색, 4장 한지와 단청) → 판 창(이름, 도전 규칙 이름과 설명, 필요한 탑, 나오는 적, 확정 보상, 편성 8칸, 난이도) → 전투. body[data-ch]로 챕터 색 변수를 바꿔 창과 단추 색도 따라가게.
3. 편성(loadout.js): 가진 탑 모음(24종 + 관리자 모드면 전용 2종), 8칸 고르기(판마다 마지막 편성 기억, need 탑 자동 추천), 탑 상세(단계별 모습과 수치, 갈래 A/B와 궁극 이름, 맞힐 수 있는 영역 표시(땅, 하늘, 바다 아이콘), 합체 조합). 전투 시작 때 newGame opts.towers에 넘김. 잠금(별 관문 gate, 챕터 open, UNLOCKS)에 따라 opts.maxLv, opts.fuse.
4. 소환과 보상: 소환 풀을 TW_RARITY(없으면 SPEC 6절 표)로, 확률 표시 갱신, 시작 탑 archer, catapult, flak, 판 첫 승리 확정 보상(M.reward: 탑이면 획득 연출, 이미 있으면 별 +1), 옛 저장 이전 안내.
5. 도감: 적을 챕터별로, 탑은 변신 나무(1 → 6단계, 갈래)로, 합체 도감(만들어 본 합체는 그림과 이름, 아직은 재료 실루엣과 물음표: SAVE.fused 기록).
6. 보너스 노드: BONUS_NODES(없으면 숨김)를 지도에 그리고 누르면 `bnOpen(node)`(XTRA 제공) 호출, `bnState(id)`로 완료 표시. 관리자: 타이틀 버전 글자에 id="ver"를 주고 XTRA가 거기에 연결. SAVE.admin이면 지도에 관리자 단추(누르면 `admOpen()`).
7. 시험: tools/touchflow.py를 새 흐름에 맞게 고쳐 360x640, 412x915 통과, tools/fitcheck.py에 새 화면(챕터 고르기, 지도 4장, 판 창, 편성, 탑 상세, 합체 도감)을 넣어 전 크기 스크롤 없이 통과, 캡처를 Read로 직접 보고 다듬기. 전투 안 화면(쟁반, HUD)은 UIB 소유이니 건드리지 말 것.

## UIB 전투 화면 (시간 예산 100분)
소유: src/style_battle.css, ui.js의 전투 HUD, 쟁반(tray), 결과 창, 일시 정지 부분, main.js의 입력 부분, tools/uib*.py
1. 건설 쟁반: 편성한 탑 최대 8종이 작은 화면(360x640)에서도 한눈에(4 x 2), 탑마다 값, 맞히는 영역 아이콘(땅, 하늘, 바다), 물 칸 전용 표시. 빈 칸을 눌렀을 때 그 칸에 지을 수 있는 탑만 밝게(물 칸이면 수상 탑).
2. 탑 쟁반: 강화, 갈래 선택(4단계: A와 B의 모습 아이콘, 이름, 한 줄 설명을 나란히 보여 주고 고르기 = 변신), 궁극(6단계: 이름과 모습 미리보기, 강조), 합체 단추(`fuseOptions(g, t)`가 있으면: 상대 탑과 결과 탑 그림, 누르면 `fuseTowers`), 능력, 판매. 잠긴 단계는 잠금 이유(어느 판을 깨면 열리는지).
3. HUD: 도전 규칙 칩(누르면 설명), 다음 웨이브 미리보기에 영역 표시(하늘, 바다 적이 오면 눈에 띄게)와 3종 이상일 때 잘리던 문제 고치기, 규칙이 건설을 막으면 알림(`ruleBlocks`).
4. 10 x 17 격자의 누르기 정확도: 칸이 36px로 작아졌으니 탭 판정, 선택 표시, 쟁반 위치가 가리지 않는지. 결과 창에 확정 보상과 변신/합체 해금 안내. 일시 정지 창에 관리자 단추(SAVE.admin이면, `admBattle()` 호출).
5. 챕터 색(body[data-ch])이 전투 HUD에도 어울리게(style_battle.css). 전투 밖 화면(타이틀, 지도, 판 창, 편성)은 UIA 소유이니 건드리지 말 것.
6. 시험: tools/uibflow.py(건설 8종, 갈래 변신, 궁극, 합체는 엔진 함수가 없으면 가짜로, 규칙 칩), touchflow 통과, fitcheck에 쟁반 상태들을 넣어 전 크기 통과, 캡처를 Read로 직접 보고 다듬기.
